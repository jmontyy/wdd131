Terraria Calamity Weapon Testing Site Plan

A resource for consistent weapon testing and ranking in the Calamity Mod community

Site Name

Calamity Weapon Testing Wiki

This name represents a website dedicated to providing information on how to undergo weapon testing.

Site Purpose

The purpose of this site is to provide a consistent resource for testing the strength and effectiveness of Terraria Calamity Mod weapons.

The website will provide testing rules, boss information, and tools to help users record and format weapon testing results. It will help players compare weapons using standardized testing methods instead of inconsistent personal experiences.

  • Testing Rules: Explains the standards and requirements used to ensure fair and consistent weapon comparisons.
  • Boss Overview: Displays important information about bosses using conditional branching to show relevant testing details.
  • Test Formatter: Allows users to enter test results and automatically generate JSON output compatible with Calamity testing and ranking utilities. Results will also be saved using localStorage.

Scenarios

These scenarios represent questions that visitors to the site may have.

  • How should I test a weapon to get accurate damage results?
  • Which bosses should I use when comparing weapons in different stages of progression?
  • How can I format my testing results so they can be used by ranking tools?

Color Schema

The website uses a dark theme with bright purple highlights to match the Calamity Mod's own stylings

  • Purple (#9944FF): Used for borders, headings, and important interface elements.
  • Light Purple (#B06BFF): Used for accents, highlighted text, and secondary headings.
  • Dark Purple (#15101D): Used for content panels and cards to create contrast against the page background.
  • Fuschia-Cyan Gradient Used for the background

Typography

The site will use the font "Exo" from Google Fonts for all typography as this matches Calamity's own usage of the font. When unavaliable, this falls back to sans-serif
